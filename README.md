# 夜市好好行 🏮 台灣在地夜市美食與生活指南

走訪全台特色夜市，發掘巷弄排隊美食、老字號小吃、即時活動資訊與交通指南。逗陣來迺夜市！

---

## 系統架構與技術棧

- **資料庫**：MongoDB (`fyp`)
- **後端 API**：Node.js + Express (Port: 7788)
- **前端 Web**：React 17 + MUI (Material-UI v5) (Port: 7789)

---

## 核心功能特色

1. **夜市導覽**：全台熱門夜市聚落探索、分區（台北/台中/台南）檢索、交通指引與評分地圖。
2. **人氣美食推薦**：分類小吃（炸物串燒、在地道地小吃、熱炒麵食、冰品甜品），標示價格與饕客評價。
3. **攤位進駐與展示**：攤商進駐申請精靈、攤位門面展示、店家招牌菜單與菜色介紹。
4. **活動公告與消息**：節慶祭典、營業公告、市集活動最新情報。
5. **饕客客棧回饋**：提供遊客意見反映、美食推薦與星級評價分享。
6. **後台管理系統**：夜市景點新增、公告發布與文宣上傳、遊客意見審核。

---

## 快速啟動

### 1. 啟動後端伺服器 (FYPServer)
```bash
cd FYPServer
npm install
node ./bin/www
# 後端服務運行於 http://localhost:7788
```

### 2. 啟動前端網站 (website_client)
```bash
cd website_client
npm install
npm start
# 前端網站運行於 http://localhost:7789
```
